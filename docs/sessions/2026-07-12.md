# 2026-07-12 — 브랜드 통일 (이모지 → 라인 아이콘, 파랑 → 퍼플)

## 배경

은아님이 타이머 화면을 보고 “이 화면이 다른 화면처럼 통일이 안 되었는데, 타이머는 기능이 많으니 이대로 가는 게 좋을까?”라고 물었다.

전날(07-11) EUNACLASS 본사이트에서 이모지 80여 곳을 라인 아이콘으로 전면 교체했다. “아이콘이 너무 AI스럽다”는 피드백이 발단이었다. 그런데 타이머 사이드바에는 이모지(⏰⏱🏁🕐)가 그대로 남아 있었고, 강조색도 파랑이라 본사이트(퍼플)와 어긋났다.

## 결정

**“기능이 많으니 이대로”와 “통일”은 별개 문제다.** 기능을 하나도 건드리지 않고 겉모습만 맞출 수 있다.

### 그대로 둔 것
- 4탭 구조(자명종·타이머·스톱워치·시계) — 기능이 많으니 이 배치가 맞다
- 거대한 숫자 — 교실 뒤에서 봐야 한다
- 프리셋(1·3·5·10분), 미니창, 전체화면
- **시작=초록, 재설정=주황** — 만국 공통 의미색이다. 브랜드 색으로 바꾸면 오히려 헷갈린다

### 바꾼 것
1. **사이드바 아이콘: 이모지 → 인라인 SVG 라인 아이콘**
   본사이트 `Y:\claude\test\js\icons.js`와 같은 규격 —
   `24x24 / fill=none / stroke=currentColor / stroke-width 1.75 / 둥근 끝단`.
   `LineIcon` 래퍼 + `AlarmIcon`·`TimerIcon`·`StopwatchIcon`·`ClockIcon` 4종을 `App.jsx`에 정의.

2. **강조색: 파랑 → 브랜드 퍼플**
   - `defaultSettings.accentColor`: `blue` → `purple`
   - 파랑 폴백 `#3b82f6` **20곳**을 `#af88ff`로 교체 (App.jsx 2 · App.css 17 · miniWindow.js 1)
   - `COLORS` 팔레트에 브랜드색 **purple `#af88ff`, teal `#5ae4d0`** 추가

3. **기존 색은 선택지로 유지** — 파랑·초록·주황·빨강·회색은 설정에서 그대로 고를 수 있다

## 함정

**일괄 치환이 팔레트까지 먹었다.** `#3b82f6` → `#af88ff` 스크립트가 `COLORS.blue: '#3b82f6'`까지 바꿔버려, 설정의 “파랑” 선택지가 퍼플이 되는 어처구니없는 상태가 됐다. 되돌렸다.

교훈: **폴백값과 팔레트값은 같은 색 코드라도 의미가 다르다.** 일괄 치환 후 반드시 팔레트를 따로 확인할 것.
