`vercel login`을 시도하자 크래시했다.

```
Error: Cannot convert argument to a ByteString because the character at index 0
has a value of 44608 which is greater than 255.
```

문자 코드 44608은 한글 음절이다. 공통 규칙(`Y:\claude\CLAUDE.md`)에 기록된 대로 **컴퓨터 이름이 한글이라 hostname을 HTTP 헤더로 변환하다 실패**하는 문제였다.

기존 토큰을 찾아 우회했다. `C:\Users\EunaKim\.claude\projects\y--claude-test\.vercel-token`에 florss58-del 계정 토큰이 있었다. (`AppData\Roaming\com.vercel.cli\Data\auth.json`은 `{}`로 비어 있었다.)
